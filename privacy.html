Privacy Policy

himalaya OAuth — last updated 13 November 2026

This policy covers the personal OAuth 2.0 client named himalaya (Google Cloud project superb-leaf-514616-r7). The client is operated by one individual for their own mailbox and is not offered as a service to the public.

1. Google user data accessed

With the owner's consent, the client requests the scope https://mail.google.com/ and accesses the owner's Gmail messages, including message bodies, headers, attachments, labels, and mailbox metadata, over Gmail's IMAP and SMTP endpoints.

2. How the data is used

The data is used only to display, search, download, compose, and send the owner's own email from the himalaya command-line client running on the owner's computer. No advertising, profiling, analytics, or automated decision-making is performed on it.

3. Storage and retention

Email data is not stored by this client beyond the owner's own machine and the owner's Gmail account. OAuth credentials are stored locally on that machine: access and refresh tokens in a file readable only by the owner (~/.local/state/ortie/paraguay.json), and the OAuth client secret in a local password store. Tokens remain until the owner revokes access or deletes the files.

4. Sharing

No Google user data and no credentials are sold, transferred, or disclosed to any third party. Data travels only between the owner's computer and Google's servers over TLS.

5. Protection

Connections use TLS. Token files use owner-only permissions. The OAuth client secret is protected by the owner's hardware security key. The client runs only on the owner's personal device.

6. Limited Use

Use of Google user data is limited to the practices described in this policy and complies with the Google API Services User Data Policy, including its Limited Use requirements.

7. Revoking access

The owner can revoke this client's access at any time at myaccount.google.com/permissions. Revocation invalidates the stored refresh token and stops all further access.

8. Contact

Questions about this policy: WillJust42@gmail.com.
